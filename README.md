# Agenda do Dono | Clube Potiguar

Agenda pessoal do Luis para o Clube Potiguar: compromissos, tarefas, lojas em negociação e diário do que foi feito.

## Como usar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador (dois cliques).
3. Os dados ficam salvos só nesse navegador (localStorage). Não há servidor nem link público.

## Backup

Use o botão **Backup** para baixar um arquivo `.json` de vez em quando. Para levar os dados para outro navegador ou aparelho, use **Restaurar backup** e escolha esse arquivo.

Limpar os dados do navegador apaga a agenda, então mantenha o backup em dia.
